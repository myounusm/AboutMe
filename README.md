# Mohammed Younus Mohiuddin — Portfolio

Personal CV and portfolio site for [Mohammed Younus Mohiuddin](https://github.com/myounusm).

## Customize

Edit **`src/content.js`** to update:

- Name, title, tagline, email, links
- About copy
- Experience roles
- Skills
- Projects

Hero image URL lives in `profile.heroImage`.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The build output is in `dist/`. `base` is set to `./` so the site works on GitHub Pages or any static host.
